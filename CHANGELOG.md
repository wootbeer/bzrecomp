# Changelog  
  
## [0.1.0 Beta] - 2026-10-14  
  
### Changed  
- No black border around the screen  
- Modern gamepad layout by default, remappable  
- Smoother ground and text at high resolutions  
### Added  
- Widescreen, with the HUD on the screen edges  
- High resolutions and frame rates  
- Screen filters: CRT, Scanlines, LCD  
- Keyboard and modern gamepad support  
- Local multiplayer with up to 4 controllers  
- Saves stored as standard Controller Pak files  
- crash_log.txt generates upon crash  
- Linux and Steam Deck build (AppImage)
