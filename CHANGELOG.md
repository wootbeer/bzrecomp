# Changelog  
  
## [0.1.1 Beta]  
  
### Added  
- Bloom option, the green HUD doesn't glow  
- Texture Filtering and HUD Filtering options: Sharp draws them with sharp pixels  
- Menus Only option for the screen filter  
- Cheats tab with the game's own codes as toggles  
- Hacks tab with GameShark codes  
### Changed  
- crash_log.txt now names the cause of more crashes  
- Much lower CPU use: the game no longer keeps a CPU core busy while it waits, for better battery life on handhelds like the Steam Deck  
  
## [0.1.0 Beta] - 2026-10-14  
  
### Changed  
- No black border around the screen  
- Modern gamepad layout by default, remappable  
- Smoother ground and text at high resolutions  
### Added  
- Widescreen, with the HUD on the screen edges  
- High resolutions and frame rates  
- Screen filters: CRT, Scanlines, LCD  
- Keyboard and modern gamepad support  
- Local multiplayer with up to 4 controllers  
- Saves stored as standard Controller Pak files  
- crash_log.txt generates upon crash  
- Linux and Steam Deck build (AppImage)
